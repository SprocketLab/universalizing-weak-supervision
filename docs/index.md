# Universalizing Weak Supervision

`uws` provides weak supervision label models for **any label type**: rankings, real values, points of a
finite metric space and manifold-valued labels. It accompanies the ICLR 2022 paper
[Universalizing Weak Supervision](https://arxiv.org/abs/2112.03865).
